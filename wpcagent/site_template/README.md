# سایت پویا — ساخته‌شده توسط ایجنت کلون وردپرس

Dynamic site generated by WordPress Clone Agent.

## اجرا / Run

**روش ساده:** دابل‌کلیک روی `run.bat`

**روش PowerShell:**
```powershell
.\run.ps1
```

سایت روی `http://127.0.0.1:8766` بالا می‌آید (مرورگر را خودتان باز کنید).

## پنل ادمین

- آدرس: `http://127.0.0.1:8766/admin`
- نام کاربری و رمز: هنگام ساخت سایت در پنل ایجنت انتخاب شده است.
- قابلیت‌ها: مدیریت نوشته‌ها و برگه‌ها، دیدگاه‌ها، گفتگوهای چت، پیام‌های تماس، رسانه‌ها، تنظیمات (نام سایت، رنگ قالب، پیام چت، سؤالات متداول)، ترجمه دستی محتوا برای هر زبان.

## قابلیت‌ها

- **پویا:** Flask + SQLite — همه‌چیز از دیتابیس خوانده می‌شود.
- **چندزبانه:** فارسی / English / عربی با کلید تغییر زبان و RTL/LTR خودکار. ترجمه محتوا را می‌توان از پنل ادمین برای هر نوشته وارد کرد؛ در نبود ترجمه، متن اصلی نمایش داده می‌شود.
- **شخصی‌سازی:** رنگ قالب و نام سایت از تنظیمات ادمین؛ حالت تیره/روشن برای هر بازدیدکننده.
- **دسترس‌پذیری (توان‌خواه):** نوار ابزار ARIA، پرش به محتوا، اندازه متن (A / A+ / A++)، کنتراست بالا، کاهش انیمیشن، ناوبری کامل با کیبورد.
- **چت آنلاین:** ربات پاسخگو بر اساس محتوای همین سایت (آفلاین). گفتگوها در ادمین قابل مشاهده و پاسخ‌دهی است.
- **جستجو، دسته‌ها، برچسب‌ها، دیدگاه‌ها، فرم تماس، مطالب مرتبط.**

## نکته امنیتی

این سایت فقط برای اجرای محلی است. برای انتشار عمومی، آن را روی سرور با `gunicorn` یا سرویس ابری اجرا کنید و رمز ادمین را عوض کنید.
